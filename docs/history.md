# Project history and authorship

The public repository was originally published as a consolidated research artifact.
That publication retained the final files but disconnected the original group
development commits from the public branch.

On 17 September 2026, the original history was recovered from a local Git bundle
and the original final-submission checkout. Two original tips were recovered:

- `139c1551b55de81d5d3c6d130c247ab478628139`: group development history.
- `a7a7baf961f39656483f85923b4d172628c1c65d`: final-submission development history.

Together they contain 77 distinct original commits. They retain their original
authors, timestamps, messages, and parent relationships, including contributions
by Alexandra Varela, Francisca Fernandes, Mariana Melo, and Tiago Antunes.

The recovery joins these histories to the public branch using a merge that keeps
the current public files. Historical notebook variants and submission folders
remain accessible in earlier commits; the root README identifies the final
artifacts to review today. No force push or replacement of the existing public
commits is needed.

The historical development snapshots are preserved as evidence of the process,
not as the recommended installation or reproduction instructions. Use the
current [README](../README.md) and [reproducibility guide](reproducibility.md).
